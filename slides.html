What the user decides

Two modes, one guarantee: the PDF is measured

Readability First

Set a minimum font (e.g. 8 pt). Never smaller. Find the fewest pages, then the largest text for that page count.

Page Count First

Set a page limit (e.g. 1). Never more. Find the largest text that fits — and warn if it is tiny.

  • Columns to print and filter columns chosen separately
  • Rows kept for values, comments or as needed parents
  • A3/A4 · portrait/landscape · 3 margin presets · repeated headings

Verified only if the real PDF passes: paper, pages, smallest font, every value/heading/comment present, nothing clipped (pixel check), safe margins. Otherwise: NOT verified with the reasons.

Architecture

Deterministic where it counts, AI where language is the input

Excel tool: Python + Microsoft Excel + a scale search over real PDFs — no language model needed. Cell values and PDF text are never sent to a model.

Safety

Financial spreadsheets are confidential

Data stays local

Excel processes a temporary copy on the user's computer; cell values never reach a language model. Hidden helper columns never leak.

The original is untouched

Macros off, copy only — SHA-256 unchanged in all 92 recorded QA runs.

Totals stay true

Formulas recalculated once, then frozen — hiding rows cannot change a SUBTOTAL. Values are never re-typed.

Honest verification

“Verified” only after measuring the real PDF; tiny text gets a warning; prompt-injection attempts on the PDF agent failed.

Value, limits, next steps

Prepare → verify → check

Value

One form instead of repeated hide-resize-print cycles; the largest readable layout; context and numbers preserved; every PDF measured.

Limits

Needs Windows + Microsoft Excel; no public deployment; tested on one real and several synthetic workbooks; .xlsx/.xlsm only; 0.5–5 min per run.
